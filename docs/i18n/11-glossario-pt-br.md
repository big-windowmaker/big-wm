# i18n do big-wm — 11. Glossário pt_BR

O glossário comum da missão está em `po/glossary/pt_BR.tsv`
(`source<TAB>translation<TAB>source of the choice`), copiado de
`/home/ruscher/.cache/bwm-wt/i18n/pt_BR.tsv`; o guia de estilo é o da
missão (português do Brasil de software, só a primeira palavra em
maiúscula, vocabulário histórico do Window Maker preservado).

Decisões deste domínio (big-wm):

| Termo | Tradução | Por quê |
|---|---|---|
| Kill / Kill Application (menu da bandeja) | Terminar / Terminar o aplicativo | o menu do appicon do wmaker (`wmaker/po/pt_BR.po`: "Terminar") |
| Force quit / Force close | Forçar o fechamento | o que os menus e o atalho já mostram (o glossário prevê "Forçar encerramento" só para títulos novos) |
| Docked Application Settings e o resto do diálogo | as frases do `wmaker/po/pt_BR.po` ("Navegar...", "Seletor de Ícones", "Travado (para prevenir remoção acidental)") | o diálogo é a réplica do do Window Maker; muda junto com ele |
| Delete (histórico) | Excluir | glossário (antes "Apagar" no diálogo e "Excluir" no botão) |
| Restore defaults | Restaurar padrões | glossário |
| OK | OK | glossário (antes "Ok") |
| New / Previous / Next (menu Áreas de trabalho) | Nova / Anterior / Próxima | feminino de "área de trabalho" (comentário `TRANSLATORS` no POT) |
| Clipboard history (dockapp) | Histórico da área de transferência | glossário |
| Screen zoom | Ampliação da tela | o que já aparecia |
| Locate pointer: on/off | Localizar o ponteiro: ligado/desligado | glossário ("On" → "Ligado") |
| On-screen keyboard | Teclado na tela | projeto (menus, bloqueio) |

Termos que o reviewer deve olhar: "Workspace pager" → "Áreas de trabalho"
(rótulo de dockapp, igual ao menu), "Busiest processes" → "Processos mais
ativos", "System layout" → "O do sistema" (opção de combo: curto de
propósito).
